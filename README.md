# Konquest - A KDE Plasma Panel Timer Game

A countdown timer for the KDE Plasma panel that shows the remaining time as two knights duelling their way across it. The knights only move while you are typing. See `GLOSSARY.md` for the terms and `docs/adr/` for the design decisions.
